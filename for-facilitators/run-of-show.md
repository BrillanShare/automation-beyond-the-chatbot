# Run of show (60 minutes)

For the presenter and co-host.

## Roles

- **Presenter:** runs a live chat with Claude and fields questions.
- **Co-host:** follows along as a "student" and keeps time.
- **Materials prep:** follows along and speaks up if relevant.

## Timeline

| Time | Block | What happens | Materials |
|---|---|---|---|
| 0:00–0:10 | Concepts | Three buckets, the deterministic definition and Venn diagram, "data type doesn't decide", tokens. Run 3–4 clear-cut examples. | web-pages/index.html (top panels), cheat-sheet.md |
| 0:10–0:40 | Participant workflows | Go deep on 2–3 participants' workflows. Run the "Agree on the design first" prompt live. Point out hard inputs and the scripting / AI-in-the-loop split. Remaining workflows: point to the handout. If participants bring few workflows, use "Sort these: discuss and vote". | web-pages/index.html ("Ask Claude first"), prompt-card.md, starter-claude-md/CLAUDE.md |
| 0:40–0:55 | Hybrid patterns | Use a participant workflow where one fits; otherwise the examples handout. Agree on the split for each pattern. Mention zero-token helpers. | demo.md and demo-files/ (two examples); web-pages/index.html ("Split the work", "Which first") |
| 0:55–1:00 | Wrap | Starter CLAUDE.md, homework, where to get the files. | starter-claude-md/CLAUDE.md, homework.md |

## If time runs short

- Skip the testing section of handout.md.
- Skip the vote; the answer key is in the handout.
- Cover zero-token helpers in one sentence and point to the handout.

## Live-demo checklist

- Show the presenter deciding: asking Claude "do this" vs. "write me a script that does this."
- Ask Claude for the hard inputs out loud, so participants see the habit.
- Ask Claude for relative tokens per run (none / small / large), not exact counts.
