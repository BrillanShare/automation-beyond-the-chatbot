# images/

Diagrams and illustrations used in the handouts (`../handout.md`, `../demo.md`) and the web pages in `../html/`.

**Don't edit these by hand.** They're drawn by `../tools/make_illustrations.py` (all except `buckets.svg` and `venn.svg`, which are hand-written SVG). To change one, edit the script and run it from the repo root:

    python tools/make_illustrations.py
