Data type doesn't decide the bucket

Numbers can need AI. Language can be scripted.

👉 What this shows: every kind of data has some tasks a script can handle and some that need an LLM. Ask what the task needs, not what kind of data it is.

How cost grows with volume

Read it like a break-even chart. Press play: the lines draw, then the marker walks through volumes and shows the cost at each.

👉 What this shows: a script costs tokens once, to build, and then stays flat. AI in the loop costs more with every item. Past the break-even point, the script is cheaper. The dashed line, comparing every item with every other, grows fastest of all.

Many tasks? Convert the biggest gap first

Four example tasks. Press play: the lines draw, then the marker walks to each firm's volume and shows what converting would save in a year.

👉 What this shows: converting saves the most where today's line is steep and your volume is high (green bars). At low volume, building the script can cost more than it saves. If every item still needs an LLM, converting saves little.

Split the work

Each pattern starts with the LLM doing every step. Press play: the steps a script can do turn blue, and the chart shows the LLM tokens that are left.

👉 What this shows: every step a script takes over flattens the token line. What remains is the LLM's share: the step that needs judgment. In the last pattern, the LLM's work happens once, so nothing is left per run.
