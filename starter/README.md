# starter/

| File | What it is |
|---|---|
| `CLAUDE.md` | Starter instructions for Claude that apply the workshop's principles: agree on the design first, controls every script needs, tests |

**What to do with it:**

- **Claude Code:** copy `CLAUDE.md` into the folder where you work on your own scripts. Claude reads it automatically.
- **Claude app:** paste its contents into a Project's instructions.
- Edit it to fit how your firm works.

It lives in its own folder so it isn't mistaken for the `CLAUDE.md` in the repo root, which is only for maintaining this repo.
